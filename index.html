上傳至 GitHub Pages 後，以 Safari「分享 → 加入主畫面」，或 Chrome 選單的「安裝／加入主畫面」使用。第一次連網開啟後即可離線使用。

請僅開啟一個視窗操作；本工具不提供跨手機同步。計時時可暫停再繼續，重開頁面也可接續尚未儲存的計時。
